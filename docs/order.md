## 2026-07-21 追加注文

- ローカル保存されるデータベースを使う
- 英単語・熟語ごとに覚えたかどうかを管理する
- 覚えている語句は出題頻度を下げる
- 覚えられていない語句、特に間違える率が高い語句は出題頻度を上げる
- 単語テストは毎回10問
- フリップ式で、最初は英語だけ表示し、タップ後に和訳を表示する
- 和訳を見た後にユーザーが「正解」「不正解」を押す
- 出題範囲はNGSL全体と、日常生活で必須の句動詞を追加する
- 毎回10問はランダム抽選にする

## 実装済み

- Expo SQLiteによる端末内DB保存
- vocabulary_itemsテーブルで語句・和訳・英語定義・出典・回答回数・正解数・不正解数・最終出題日時を管理
- 10問固定のテストセッション
- カードタップで和訳表示
- 正解/不正解ボタン
- 不正解率に応じた重み付きランダム出題
- NGSL 1.01英日CSV 2801件の初回DB投入
- 日常頻出句動詞スターター50件の初回DB投入

## 実装済み: PWA

- React + ViteのPWAへ切り替え
- GitHub Pages向けのビルド設定
- GitHub ActionsによるPages自動デプロイ設定
- Web app manifestとservice workerを追加
- IndexedDBに語句マスター、累計成績、回答履歴を保存
- Web Speech APIで英語読み上げ
- 10問終了後に英語・日本語・正解/不正解を必ず表示
- 学習データのJSONバックアップ
- 学習履歴リセット

## PWAデータ設計

- `items`: NGSL/句動詞の語句マスター、和訳、英語定義、出典、出題回数、正解数、不正解数、最終出題日時
- `attempts`: 1回答ごとの履歴、語句ID、正解/不正解、回答時刻、セッションID、表示用の英語/日本語
- `meta`: seed versionなどの内部管理

サーバーには学習履歴を保存しない。無料ホスティングはアプリ本体を配信するだけにする。
